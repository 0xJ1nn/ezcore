# Rules for AI coding agents

This repository is the public ezCORE app. If you are an AI tool helping
someone contribute, follow [`CONTRIBUTING.md`](CONTRIBUTING.md). In short:

- Never add ROMs, BIOS or firmware files, keys, game art, box scans or
  commercial game titles, not even in tests, mockups or screenshots. Use
  invented titles.
- Never add design studies, prototypes, agent configuration or working notes.
  This repository contains the product only.
- Commit under the contributor's real identity, sign off (`git commit -s`),
  and disclose AI assistance with an `Assisted-by:` trailer.
- Run `flutter analyze` and `flutter test` before opening a pull request, and
  state the claim you can prove: implemented, tested, boots or plays.
- Public text is finished prose for a reader. Do not narrate your process.
