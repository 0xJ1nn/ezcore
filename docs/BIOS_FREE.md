# ezCore — BIOS-Free Operation

> **Version:** 1.0
> **Date:** 2026-10-18
> **Scope:** the nine cores in `cores/catalog.json` with `bios_required: true` or a non-empty `bios_files`.

---

## Policy

ezCORE never ships, bundles, downloads, or inspects console firmware. The host app's only BIOS involvement is an existence check: `BiosCheck` calls `existsSync`/`listSync` on the user's `system/` directory and never opens, hashes, or parses a dump (`lib/services/bios_check.dart:33-43,70-88`). User dumps stay opaque and local — no game, BIOS, or copyrighted asset ships with the app (`docs/LOCAL_DATA.md:10`), and the iOS artifact ships no BIOS or sourcing guidance. Cores must reach a usable state through an in-tree open/HLE BIOS, a clean-room implementation, or a dump the user supplies from their own hardware. No console firmware, firmware disassembly, decryption key, or leaked SDK material is used or referenced by this document or by ezCORE.

"Open path" below means the shipped core can boot content without a user dump; it does not mean the replacement is cycle-accurate or licence-free of every upstream provenance question (see **Unverified**).

## Recommended next actions

### A. Core already ships an open path — enable it

1. **`dualscreen` (highest impact, one-line fix).** Set `bios_required: false` in `cores/dualscreen/manifest.json`; the DS path needs no dump at all (FreeBIOS + generated firmware). Keep `bios_files` as optional import metadata so real dumps still override FreeBIOS. Do not gate boot on `bios7.bin`/`bios9.bin`/`firmware.bin`.
2. **`geometry1` (no code change).** `bios_required` is already `false`, and OpenBIOS loads automatically. Document that the three `scph*.bin` files are optional quality upgrades, not requirements; the current manifest's "any one of the three" phrasing is misleading because none is needed.
3. **`dreamarc` (unlock the HLE fallback).** Set `bios_required: false` (real BIOS remains preferred when present) or special-case it in `BiosCheck`; the core already falls back to REIOS when `dc_boot.bin` is absent. If the launcher is to force it, add a per-core default `reicast_hle_bios=enabled` (`CoreOptionsResolver` supports per-core defaults). Keep a compatibility warning for the forced-real-BIOS list at `core/emulator.cpp:267-279`, and leave NAOMI gated because it needs `naomi.zip`.

### B. No open path found

4. **`lrps2` / PS2.** Keep LRPS2 gated on a user dump, but route "no BIOS" users to `dualvu` — this repo's Play! `ui_libretro` build (`scripts/build_core.sh` `build_dualvu`, pinned `DUALVU_SHA=d44bfa1`) boots PS2 ELF/homebrew with no firmware (`cores/dualvu/manifest.json`). Linux x64 is verified (`ctest -R boot_dualvu`, 2026-10-18) with three local BSD-2-compatible patches in `patches/play/`: libretro teardown (drain the GS mailbox instead of `Release()`ing GL objects), an IPU PACK null-slot guard, and a direct hex parser for save-state registers (GCC 16 miscompiles the iostream path). Do not attempt to reuse PCSX2's IOP HLE as an EE BIOS; it is IOP-only.
5. **`blastproc` / Sega CD.** Correct the manifest first: list `bios_CD_U.bin`, `bios_CD_E.bin`, `bios_CD_J.bin` (required for `scd`) and the real optional names `bios_U.sms`, `bios_E.sms`, `bios_J.sms`, `bios.gg`, `bios_MD.bin`. No open Sega CD boot ROM found; keep CD gated and per-content, not per-core.
6. **`cardcon` / PC Engine CD.** Keep `bios_required: false` for HuCards but add a per-content warning when a `pcecd`/`cue`/`chd`/`m3u` title is launched and `syscard3.pce` is absent; the core option defaults to that exact filename. No open System Card found.
7. **`nesbyte` / FDS.** Keep the per-core flag false and add a per-content check for `.fds` requiring an 8 KiB `disksys.rom`. No open FDS BIOS found.
8. **`coinbox` / Neo Geo.** Keep the per-core flag false; detect Neo Geo sets and require `neogeo.zip` (board ROM `neogeo`). No HLE found; do not treat `neopen.sp1` as an open replacement without provenance.
9. **`twinsh` / Saturn.** Keep the hard gate. There is no open path in beetle-saturn; the only HLE precedent found is Yabause's `emulatebios`, which is a different emulator and refuses CD-block LLE. A port would be a clean-room research project, not a configuration change.

## Unverified

- **NeoOpen BIOS v0.1 beta (`neopen.sp1`)** — named as an optional Neo Geo BIOS entry in FBNeo (`d_neogeo.cpp:1701`), but no source repository or licence was found. Not treated as open; do not ship or recommend it.
- **Dreamcast REIOS provenance** — `core/reios/reios.cpp:4-7` thanks a third party for "bios decompile work" and links historical `bootROM.c` files. The HLE is GPL-2.0-or-later like the rest of Flycast, but whether that derivation is clean-room was not established.
- **Play! HLE completeness** — the BIOS-free boot path is verified on one CC0 homebrew ELF (`boot_dualvu`). Coverage of commercial titles was not audited here; Play! upstream describes its HLE as incomplete. A crash seen during integration was reproduced as teardown/state-restore races and fixed in `patches/play/`, not an EE-emulator limitation.
- **Yabause Saturn HLE coverage** — `emulatebios` exists (`yabause.c:354-355`, `sh2int.c:235-238`), but its game compatibility and whether it could be ported to beetle-saturn were not audited.
- **No open replacement found** in the surveyed upstream trees for: Sega CD boot ROM, PC Engine CD System Card, FDS `disksys.rom`, Saturn BIOS, PS2 EE ROM, Neo Geo board ROM. Absence of evidence in these specific commits is not proof that none exists.
- **OpenBIOS on real hardware/arcade boards** — its README documents cart/System 573/ZN builds, which were not exercised here; only the emulator path is in scope.
- **`blastproc` licensing** — the upstream licence is non-commercial and per-file terms are not uniform; the row records the repo-level terms only.

## Method

Upstream files were read at the pinned commits above via `raw.githubusercontent.com`; no firmware, BIOS image, key, or disassembly was downloaded. The only binary in scope is the in-tree `dep/openbios/openbios.bin` snapshot committed by SwanStation, whose adjacent `LICENSE.txt` is the MIT licence from PCSX-Redux. Repo-side claims cite the working tree (`docs/`, `lib/`, `cores/`, `scripts/`).
